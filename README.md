# GrafikAI-Creative-Partner-for-DKV
GrafikAI — Creative Partner for DKV  GrafikAI adalah platform berbasis kecerdasan buatan (AI) yang dirancang untuk membantu siswa dan desainer DKV (Desain Komunikasi Visual) mengembangkan kreativitas. GrafikAI menyediakan berbagai fitur, seperti generator ide desain, rekomendasi palet warna, tipografi, pembuatan konsep poster, dan prompt desain.
